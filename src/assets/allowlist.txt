# Domains the sandboxed agent may reach, one per line.
#
# A bare name matches that host exactly. A leading dot matches the domain and
# every subdomain. A name with an explicit port, such as
# 'host.container.internal:27182', is a host service: it is allowed on that port
# only, and the proxy may dial a non-public address for it (here, the Mac's
# address on the container network). Blank lines and lines starting with '#' are
# ignored. Only ports 80 and 443 are proxied for ordinary names; host services
# use the port they name.
#
# This file is the whole allowlist. No other host is reachable: the firewall drops
# every packet the agent sends directly, so a host that is not named here is
# unreachable even by IP address.
